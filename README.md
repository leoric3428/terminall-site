# terminall.app

terminALL'ın tanıtım, gizlilik ve destek sayfaları. Düz HTML/CSS, derleme adımı yok.

- `index.html` — tanıtım
- `privacy/` — gizlilik politikası (App Store Connect'in istediği adres)
- `support/` — destek/iletişim (App Store Connect'in istediği adres)
- `lang.js` — dil geçişi; tarayıcı Türkçeyse Türkçe açılır, seçim tarayıcıda kalır
- `img/` — mağaza görsellerinden kırpılmış ekran kareleri

Yerelde bakmak için: `python3 -m http.server 8877`
